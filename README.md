# 🛍️ E-Commerce Analytics Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **E-Commerce Analytics Dashboard** developed using **Microsoft Power BI** to analyze and compare product data from **Amazon, Flipkart, and Myntra**.

The dashboard provides insights into pricing, discounts, ratings, reviews, categories, brands, and overall platform performance.

## 🎯 Objectives

- Compare e-commerce platforms based on pricing and discounts
- Analyze product ratings and customer reviews
- Identify category-wise and brand-wise trends
- Analyze average selling price and original price
- Identify products and categories with higher discounts
- Build an interactive and visually appealing Power BI dashboard

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel / CSV**
- **Data Cleaning & Transformation**
- **Data Visualization**
- **Exploratory Data Analysis**

## 📂 Dataset

The analysis uses product-level e-commerce datasets from:

- Amazon
- Flipkart
- Myntra

The datasets contain information such as:

- Product Name
- Brand
- Category
- Selling Price
- Original Price
- Discount
- Rating
- Reviews
- Platform

## 📈 Dashboard Pages

### 1. Executive Overview
Provides an overall comparison of the three e-commerce platforms using key performance indicators and visual summaries.

### 2. Amazon Analysis
Analyzes Amazon products based on pricing, discounts, ratings, reviews, brands, and categories.

### 3. Flipkart Analysis
Provides detailed insights into Flipkart product pricing, discounts, ratings, and categories.

### 4. Myntra Analysis
Analyzes Myntra's extensive product catalog with category-wise, pricing, discount, and rating analysis.

### 5. Platform Comparison
Compares Amazon, Flipkart, and Myntra to identify differences in pricing, discounts, ratings, and product distribution.

## 🔍 Key Insights

The dashboard helps identify:

- Average selling price across platforms
- Average discount by category
- Product and category distribution
- Rating patterns
- Review volume
- Brand and category performance
- Differences in pricing and discount strategies across platforms
